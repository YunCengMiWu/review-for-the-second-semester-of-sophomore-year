# AD转换
要修改**通道号、引脚、左右对齐方式、采样时间**，你需要改动以下具体参数：

---

## 1. **修改通道号和对应引脚**

### 引脚初始化部分（`Adc_Init` 函数开头）
```c
GPIOA->CRL &= ~0xFFFFFFFF; // PA1 analog输入
```
- 如果改用其他引脚（如 PA2、PA3 或 PAx），需要修改对应的 GPIO 端口和引脚配置。
- 不同通道对应的引脚：
  - **ADC1 通道 0** → PA0
  - **ADC1 通道 1** → PA1
  - **ADC1 通道 2** → PA2
  - **ADC1 通道 3** → PA3
  - 通道 10/11 对应 PC0/PC1（需使能 PORTC 时钟）

### 规则序列设置（`Get_Adc` 函数）
```c
ADC1->SQR3 |= ch;
```
- 调用 `Get_Adc(ch)` 时，`ch` 就是通道号（0~17 等）。

---

## 2. **修改左右对齐方式**

在 `Adc_Init` 中找到：
```c
ADC1->CR2 &= ~(1 << 11);    // 右对齐
```
- **右对齐**：`ADC1->CR2 &= ~(1 << 11);`
- **左对齐**：`ADC1->CR2 |= (1 << 11);`

---

## 3. **修改采样时间**

在 `Adc_Init` 中找到对应通道的采样时间设置（示例为通道1）：
```c
ADC1->SMPR2 &= ~(7 << 3);    // 通道1采样时间清空
ADC1->SMPR2 |= 7 << 3;       // 通道1 239.5周期
```
- 你需要根据**目标通道号**修改移位位数：
  - 通道 0~9 使用 `SMPR2`，偏移 = `通道号 × 3`
  - 通道 10~17 使用 `SMPR1`，偏移 = `(通道号 - 10) × 3`

### 采样时间编码（3位）：
| 编码 | 周期数 |
| ---- | ------ |
| 000  | 1.5    |
| 001  | 7.5    |
| 010  | 13.5   |
| 011  | 28.5   |
| 100  | 41.5   |
| 101  | 55.5   |
| 110  | 71.5   |
| 111  | 239.5  |

例如，通道 3 采样时间 55.5 周期：
```c
ADC1->SMPR2 &= ~(7 << (3*3));   // 清空位 9~11
ADC1->SMPR2 |= (5 << (3*3));    // 55.5周期
```

| -------- | ---------- | ------------------- | ---------------------- |
| 引脚     | `Adc_Init` | GPIOx_CRL/CRH       | 改端口和引脚模式       |

| 对齐方式 | `Adc_Init` | `ADC1->CR2` 位11    | 置1=左对齐，清0=右对齐 |
