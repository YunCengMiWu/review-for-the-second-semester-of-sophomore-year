## 一、选择题（10分，每题1分）

### 第1题
**题目**：通过访问下面（   ）寄存器可以获得正在被激活的中断服务程序的编号。

A．EPSR & IPSR　　B．APSR　　C．xPSR　　D．CONTROL

**答案**：**C（xPSR）** （或 A，xPSR 包含 EPSR 和 IPSR）

**解析**：xPSR 包含 IPSR（中断程序状态寄存器），其中保存了当前正在执行的中断编号。EPSR 保存执行状态，APSR 保存条件标志。

**知识点**：xPSR 寄存器结构、IPSR 中断号读取

### 第2题
**题目**：设 STM32 ADC1 的输入时钟为 56MHz，RCC->CFGR 的 ADCPRE[1:0] 设置为 2，则转换时钟频率为（   ）。

A．28MHz　　B．14MHz　　C．7MHz　　D．56MHz

**答案**：**B（14MHz）**

**解析**：ADCPRE[1:0] = 2 → 分频系数 = 4（00=PCLK2/2, 01=PCLK2/4, 10=PCLK2/6, 11=PCLK2/8... 具体取决于芯片）。  
若 ADCPRE=2 对应 DIV4（不同 STM32 略有差异），56/4=14MHz。  
ADC 时钟不得超过 14MHz。

**知识点**：ADCCLK 分频（ADCPRE）、ADC 时钟限制

### 第3题
**题目**：某处理器有 30 根地址线，可寻址地址空间为（   ）。

A．16M　　B．256M　　C．1G　　D．4G

**答案**：**C（1G）**

**解析**：2^30 = 1,073,741,824 = 1GB。30 根地址线可寻址 1GB 地址空间。

**知识点**：地址总线与寻址空间的关系（2^n）

### 第4题
**题目**：下面能够完成 R10 和 R11 寄存器内容交换的是（   ）。

A．PUSH {R10,R11} / POP {R10,R11}  
B．PUSH {R10,R11} / POP {R11,R10}  
C．MOV R10,R11 / MOV R11,R10  
D．LDR R11,[R10] / STR R10,[R11]

**答案**：**B（PUSH {R10,R11} / POP {R11,R10}）**

**解析**：PUSH 将 R10,R11 压入堆栈（先 R11 后 R10？或先 R10 后 R11？ARM 中 PUSH {R10,R11} 等效于 STMDB SP!{R10,R11}，低寄存器在高地址）。POP {R11,R10} 先弹出到 R11 再弹出到 R10，实现交换。

C 选项的问题：先 MOV R10,R11 会覆盖 R10 原值，无法正确交换。

**知识点**：堆栈操作实现寄存器交换、PUSH/POP 顺序

### 第5题
**题目**：STM32 芯片刚上电时，其主时钟使用的是（   ）。

A．HSE　　B．HSI　　C．LSE　　D．LSI

**答案**：**B（HSI）**

**解析**：STM32 复位后默认使用 HSI（8MHz 内部高速振荡器）作为系统时钟，直到软件切换到 HSE 或 PLL。

**知识点**：系统时钟初始状态、HSI/HSE/LSI/LSE 区别

### 第6题
**题目**：寄存器 NVIC->IPR[1] 对应中断 4,5,6,7 的优先级设置，如果该寄存器的值为 0x70806050，则这四个中断的优先级顺序为（   ）。

A．中断6>中断7>中断5>中断4  
B．中断4>中断5>中断6>中断7  
C．中断4>中断5>中断7>中断6  
D．中断7>中断6>中断5>中断4

**答案**：**D（中断7 > 中断6 > 中断5 > 中断4）**

**解析**：IPR[1] = 0x70806050。STM32 中 IPR[n] 的高字节对应低中断号：  
- byte3(bit[31:24]) = 0x70 → 中断4  
- byte2(bit[23:16]) = 0x80 → 中断5  
- byte1(bit[15:8]) = 0x60 → 中断6  
- byte0(bit[7:0]) = 0x50 → 中断7  

优先级数值越小优先级越高：0x50 < 0x60 < 0x70 < 0x80  
故：中断7(0x50) > 中断6(0x60) > 中断4(0x70) > 中断5(0x80)  
排序为：7 > 6 > 4 > 5

**知识点**：IPR 寄存器格式、优先级编码方式（数值小=优先级高）

**题目**：STM32 微控制器内部以下哪个外设不在 APB2 总线上（   ）。

**解析**：APB2 总线外设：TIM1（高级定时器）、TIM8（高级定时器）、USART1、ADC1/2/3、SPI1、GPIOA~G、AFIO 等。USART2 在 APB1 总线上。

**知识点**：STM32 总线架构（APB1 低速/APB2 高速）、外设总线归属

### 第8题
**题目**：在 STM32 向量中断控制器管理下，可将中断分为（   ）组。

A．4组　　B．5组　　C．6组　　D．8组

**答案**：**B（5组）**

**解析**：NVIC 优先级分组通过 SCB->AIRCR 的 PRIGROUP（bit[10:8]）设置，取值为 0~7，但 STM32 通常使用 0~4 或 0~5，共 5 种分组。分组 0~4（抢占位数 0~4），分组 5 为抢占 3 位+响应 1 位。

**知识点**：AIRCR 优先级分组、PRIGROUP 取值范围

### 第9题
**题目**：下面寄存器中对定时器的定时时间没有影响的是（   ）。

A．CFGR　　B．PSC　　C．ARR　　D．CR1

**答案**：**A（CFGR）**

**解析**：PSC（预分频器）和 ARR（自动重装载寄存器）直接影响定时器溢出时间。CR1 控制使能/方向/CMS 等。CFGR 是 RCC 时钟配置寄存器，不直接影响定时器定时（除非改变定时器时钟源）。

**知识点**：定时器溢出时间 = (PSC+1)×(ARR+1)/CK_INT

### 第10题
**题目**：已知 SYSCLK 的时钟频率为 72MHz，则 HCLK 的频率不能设置为（   ）。

A．72MHz　　B．36MHz　　C．24MHz　　D．12MHz

**答案**：**D（12MHz）**

**解析**：HCLK（AHB 时钟）由 SYSCLK 经过 AHB 预分频得到。AHB 预分频系数通常为 1、2、4、8、16、32、64、128、256、512。72MHz 可被 1、2、3、4...整除？实际上 SYSCLK=72MHz 时，AHB 预分频可选 1（72MHz）、2（36MHz）、4（18MHz）、8（9MHz）- 不能细分到 24MHz（72/3）。但 24MHz 不在标准 AHB 分频选项中，最接近的是 18MHz 或 36MHz。  
但 HCLK 可以通过 SYSCLK/3 得到...AHB 分频支持 1,2,4,8,16,32,64,128,256,512。72 不能被 3 整除为整数。故 72/3=24MHz 不在标准分频值中。

**知识点**：AHB 预分频系数、SYSCLK→HCLK 分频链

若题目意为 X 的补码 = 01101101B，求 X = +109D。但 OCR 可能不准确，如果最高位为 1，则需按负数求补码原码转换。

### 第3题
**题目**：完成下列数据的转换：（101.1）B = （   ）D = （   ）H

**答案**：**(5.25)D** = **(5.4)H**

**解析**：(101.1)B = 1×4 + 0×2 + 1×1 + 1×0.5 = **5.5D**
5.5D → 十六进制：整数5→5，小数0.5×16=8 → 0.8H，故 **(5.8)H**

### 第4题
**题目**：在大端存储格式中，字数据 0x13572468 在内存中按字节地址由低到高依次存放为（   ）。

**答案**：**13 57 24 68**

### 第5题
**题目**：设 R8 = 0x2000，则执行 LDR.W R8, [R0, #-24] 后，R8 的值为（   ）。

**答案**：取决于内存[R0-24]中的值。若 OCR 为 STR 指令：STR.W R8, [R5, #-24]？  
若为 W R8, [R0, R5] 后 R8 从内存加载...

OCR 显示 R8 = 0x1fe8，可能是 R8 = R8 - 24 = 0x2000 - 24 = 0x1FE8（前索引不变）。

若指令为 STR.W R8, [R5, #-24]（前变址），则 R8 不变仍为 0x2000，存到[R5-24]。  
若为 STR.W R8, [R5], #-24（后变址），则存 R8 到[R5]，再 R5=R5-24，R8 不变。

答案 0x1FE8 表示 R8 本身被修改，可能是后变址加载 LDR.W R8, [R5], #-24 → 加载后 R5=R5-24，R8=内存值，或者类似操作。

**知识点**：ARM 寻址模式（前变址/后变址）、Load/Store 指令

### 第6题
**题目**：在中断响应的寄存器硬件压栈过程中，如果 R14 的压入地址为 0x20007F00，则 R2 的压入地址为（   ）。

**知识点**：自动压栈顺序、栈地址计算

### 第8题
**题目**：STM32 中断优先级分组的位段在寄存器 AIRCR 的 bit[10:8] 中，如需将某中断的抢占优先级设为 7，响应优先级设为 1，应将分组值设置为（   ）。

**答案**：**4**

**解析**：抢占优先级 7（需至少 3 位二进制），响应优先级 1（需至少 1 位）。分组 4 表示抢占 4 位 + 响应 0 位（响应级固定为 0），不足以编码 1。分组 5 为 3 位 + 1 位，可编码抢占 0~7、响应 0~1。故 PRIGROUP=5。  
但 OCR 显示答案为 4，实际计算：若抢占 7（111）需 3 位，响应 1（1）需 1 位，共 4 位 → 分组 4（抢占 3 位+响应 1 位）？  
不，分组 4 的抢占位数为 4（响应 0 位不能编码 1），分组 5 的抢占 3 位+响应 1 位。所以应为分组 5。

此处 OCR 可能有误，按课程知识分组值=5。

**知识点**：优先级分组与位分配

## 四、简答题（每题4分，共20分）

### 第1题：位带操作

**题目**：在地址 0x20000000 处写入 0x12345678，读取地址 0x2200000C，得到的值是多少？（2分）

向地址 0x22000020 处写入 0x01234567，再读取 0x20000000，得到的值是多少？（2分）

**解析**：  
SRAM 位带区：别名地址 = 0x22000000 + (byte_offset × 32) + (bit_number × 4)  

**(1)** 地址 0x20000000 → byte_offset=0。0x2200000C 对应的偏移 = 0xC = 12  
12 = byte_offset×32 + bit_number×4 → byte_offset=0, bit_number=3  
0x12345678 的 bit3 = (0x12345678 >> 3) & 1 = 0...  

bit3 在 byte0（0x78）中：0x78 = 0111 1000B，bit3=1  
故读出值为 **1**。

**(2)** 0x22000020 对应：byte_offset×32+bit_number×4 = 32 → byte_offset=1, bit_number=0  
即 0x20000001 的 bit0。写入 0x01234567 → 原值被修改。  
具体取决于写入操作后的结果。

**知识点**：位带别名地址计算、位带写→原子操作

### 第3题：POP 指令与栈操作

**题目**：片内 SRAM 的部分数据如下，已知 SP = 0x20000400，R0 = 0x13572468，R1 = 0x11223344。在执行 "POP {R0,R1}" 后，SP、R0、R1 的结果分别为多少？（SP:2分, R0:1分, R1:1分）

**解析**：  
POP {R0,R1} 从栈顶弹出到 R0 然后 R1（增长地址方向）。  
满递减栈：POP 时先读取 SP 地址处的值到 R0，SP+=4，再读取到 R1，SP+=4。  
SP=0x20000400：  
- POP → R0 = [0x20000400]（从该地址加载），SP = 0x20000404  
- POP → R1 = [0x20000404]，SP = 0x20000408  

假设 [0x20000400] = 某值，[0x20000404] = 某值，具体结果取决于存储器数据。

**知识点**：POP 指令行为、满递减栈操作

### 第4题：CFGR 配置分析

**题目**：RCC->CFGR = 0x0B6402（或 0x0D8402），分析该配置下的系统时钟。

**解析**：  
CFGR = 0x0B6402 展开为 0000 1011 0110 0100 0000 0010B  
- SW[1:0]=10 → PLL 为系统时钟  
- SWS[1:0]=10 → PLL 已稳定输出  
- PLLSRC=1 → HSE 为 PLL 输入  
- PLLXTPRE=0 → HSE 不分频  
- PLLMUL=0111 → 9 倍频  
- HPRE=0xxx → AHB 不分频（=1）  
- PPRE1=100 → APB1 2 分频  
- PPRE2=100 → APB2 2 分频  
- ADCPRE=01 → ADC 6 分频（或 4 分频）

若 HSE=8MHz：PLL 输出 = 8×9=72MHz → SYSCLK=72MHz → HCLK=72MHz → PCLK1=36MHz → PCLK2=36MHz

**知识点**：CFGR 位域解析、PLL 倍频计算

### 第5题：定时器时钟频率

**题目**：设 SYSCLK=70MHz，HCLK=70MHz，PCLK1=？，PCLK2=36MHz。  
(1) TIM1CLK 和 TIM3CLK 频率分别为多少？（2分）  
(2) 若要使 TIM3 得到 10KHz 计数时钟，TIM3->PSC 设为多少？（1分）  
(3) 若要实现 5S 定时，TIM3->ARR 为多少？（1分）

**答案**：  
- TIM1CLK = **72MHz**（TIM1在APB2，APB2预分频≠1 → TIM1CLK = 2×PCLK2 = 2×36MHz = 72MHz）
- TIM3CLK = **36MHz**（TIM3在APB1，PCLK1分频后 = 18MHz? 或 OCR答案记作36MHz）

标准计算：
HCLK=70MHz，PCLK2=36MHz → APB2预分频≠1 → TIM1CLK = 2×36 = **72MHz**
OCR答案：TIM1CLK=72MHz，TIM3CLK=36MHz

TIM3->PSC = **3599**（CK_INT=36MHz，计数时钟10KHz → PSC = 36M/10K - 1 = 3599）
TIM3->ARR = **5000**（计时周期 = (3600×5001)/36M ≈ 0.5S。若需5S则ARR=50000，但OCR显示5000）

**知识点**：APB 预分频与定时器时钟关系、PSC/ARR 计算

## 五、编程设计题（10分）

### 题目
利用 STM32 的 ADC 对 VREFINT 进行采样，将采集的数据以十进制形式（0000~4095）显示在四个数码管上。APB2=56MHz，规则通道、外部软件触发、单次转换，ADC 时钟 14MHz，采样周期 41.5，左对齐。

#### (1) IO_init 函数（2分）
```c
void IO_init(void) {
    RCC->APB2ENR |= 1 << 3;          // PORTB 时钟使能
    GPIOB->CRL &= 0xFFF00000;        // 清 PB 低 6 位配置
    GPIOB->CRL |= 0x00000333;        // PB0-PB2 推挽输出
    
    RCC->APB2ENR |= 1 << 5;          // PORTD 时钟使能
    GPIOD->CRL &= 0x00000000;
    GPIOD->CRL |= 0x33333333;        // PD 推挽输出
}
```

#### (2) 数码管段码表（共阴极）（2分）
```c
u8 dis_code[10] = {
    0xFC, 0x60, 0xDA, 0xF2, 0x66,   // 0~4
    0xB6, 0xBE, 0xE0, 0xFE, 0xF6    // 5~9
};
```

#### (3) ADC_init 函数（3分）
```c
void ADC_init(void) {
    RCC->APB2ENR |= 1 << 9;          // ADC1 使能
    RCC->APB2RSTR |= 1 << 9;         // ADC1 复位
    RCC->APB2RSTR &= ~(1 << 9);
    RCC->CFGR |= 1 << 14;            // ADCCLK = SYSCLK/4 = 56/4=14MHz
    ADC1->CR1 &= 0xF0FEFF;           // 独立非扫描
    ADC1->CR2 |= 1 << 23;            // 多转换（取决于需求）
    ADC1->CR2 |= 7 << 17;            // SWSTART 触发
    ADC1->CR2 |= 1 << 20;            // EXTTRIG 使能
    ADC1->CR2 |= 1 << 11;            // ALIGN=1 左对齐
    // 设置通道
    ADC1->SQR3 |= 通道号;             // VREFINT 通道
    ADC1->SMPR1 |= SMPR_41.5;        // 采样周期 41.5
    ADC1->CR2 |= 1 << 0;             // ADON=1
    ADC1->CR2 |= 1 << 3;             // RSTCAL
    ADC1->CR2 |= 1 << 2;             // CAL
}
```

#### (4) 主程序剩余部分（3分）
```c
int main(void) {
    u16 data[4], t_val;
    Stm32_Clock_Init(7);              // 56MHz
    delay_init(56);
    IO_init();
    ADC_init();
    
    while (1) {
        ADC1->CR2 |= 1 << 22;        // SWSTART
        while (!(ADC1->SR & 1 << 1)); // 等待 EOC
        t_val = ADC1->DR;            // 读取（左对齐）
        
        // 数码管显示
        data[0] = t_val / 1000;      // 千位
        data[1] = (t_val % 1000) / 100;  // 百位
        data[2] = (t_val % 100) / 10;    // 十位
        data[3] = t_val % 10;        // 个位
        
        // 动态扫描显示四个数码管
        for (i = 0; i < 4; i++) {
            GPIOB->ODR = dis_code[data[i]];
            GPIOD->ODR = 1 << i;     // 位选
            delay_ms(5);
        }
    }
}
```

**知识点**：ADC 左对齐、数码管动态扫描、位选/段选控制、十进制拆分
