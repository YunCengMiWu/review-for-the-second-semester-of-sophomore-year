### 第1题
**题目**：下面定时器中，（   ）支持 PWM 互补输出。

A．TIM2　　　B．TIM4　　　C．TIM6　　　D．TIM8

**答案**：**D（TIM8）**

**解析**：STM32 中只有**高级定时器 TIM1 和 TIM8** 支持 PWM 互补输出、死区插入等功能。TIM2~TIM5 是通用定时器，TIM6/TIM7 是基本定时器。

**知识点**：STM32 定时器分类——高级/通用/基本

**答案**：**C（4GB）**

### 第3题
**题目**：STM32 微控制器复位后处于什么特权级别和操作模式（   ）。

A．特权级 Handler 模式　　　B．特权级线程模式  
C．用户级 Handler 模式　　　D．用户级线程模式

**答案**：**B（特权级线程模式）**

### 第5题
**题目**：中断 6 的抢占优先级为 2，响应优先级为 2；中断 7 的抢占优先级为 3，响应优先级为 0；中断 8 的抢占优先级为 2，响应优先级为 1。则这 3 个中断的优先级顺序为（   ）。

A．中断 6 > 中断 7 > 中断 8　　　B．中断 8 > 中断 7 > 中断 6  
C．中断 7 > 中断 8 > 中断 6　　　D．中断 8 > 中断 6 > 中断 7

**答案**：**D（中断 8 > 中断 6 > 中断 7）**

**解析**：CM3 中优先级**数值越小优先级越高**。先比抢占：中断 7(3) 最大 → 最低。中断 6 和 8 同为 2，比响应：中断 8(1) < 中断 6(2) → 中断 8 > 中断 6。故从高到低：中断 8 > 中断 6 > 中断 7。

**知识点**：NVIC 优先级比较规则、抢占 vs 响应优先级

### 第8题
**题目**：下面能够完成 R0 和 R1 寄存器内容交换的是（   ）。

A．PUSH {R0, R1}; POP {R0, R1}　　　B．PUSH {R0, R1}; POP {R1, R0}

### 第1题：位带操作

**题目**：在地址 0x20000000 写入 0x3355AACC，读取 0x2200000C 得何值？向 0x22000014 写 1，再读 0x20000000 得何值？

**答案**：
- **0x2200000C** 读出：**1**
- 写 1 后 **0x20000000**：**0x3355AAEC**

**解析**：
**第一问**：偏移=0xC=12，byte_offset=0，bit=3。0xCC=11001100B，bit3=1 → 读出 **1**。

**知识点**：位带别名地址读写

### 第5题：外部中断优先级配置

**题目**：设置外部中断 49# 为抢占 1 级、响应 4 级，完成代码填空。

**答案**：
```c
temp &= 0x0000F8FF;          // 清除 PRIGROUP
temp |= 0x05FA0000;          // 写入钥匙
temp |= 0x00000600;          // PRIGROUP=6（抢占1位+响应3位）

NVIC->ISER[1] |= 1 << 17;    // 49-32=17
```

**解析**：PRIGROUP=6（分组6：抢占1位+响应3位）。抢占1、响应4 → 高4位=(1<<3)|4=12=0xC。IPR[12]高8位=0xC0，写入 0xC0000000。

**知识点**：NVIC 中断使能与优先级配置、AIRCR 分组、IPR 位偏移

### 第6题：定时器 20ms 定时

**题目**：系统时钟 72MHz，编程使 TIM3 实现 20ms 定时。

**答案**：
```c
void TIM3_20ms_Init(void)
{
    RCC->APB1ENR |= 1 << 1;    // TIM3 时钟使能
    TIM3->PSC = 7199;           // 72M/7200=10KHz
    TIM3->ARR = 199;            // 10KHz×200=20ms
    TIM3->DIER |= 1 << 0;       // 更新中断使能
    TIM3->CR1 |= 1;             // 使能
}
```

**知识点**：TIM 预分频器(PSC)、自动重装载(ARR)、定时时间计算

**题目**：简述哈佛结构与冯·诺依曼结构的区别。

**答案**：

|:----:|:--------:|:--------------:|

## 五、编程设计题（10分）

### 题目概述

SYSCLK=72MHz，HCLK=72MHz，PCLK2=72MHz，PCLK1=36MHz。

#### （1）初始化 USART1（3分）

要求：8 数据位、1 停止位、无校验、波特率 57600bps。

```c
void USART1_Init(void)
{
    // 使能 USART1 和 GPIOA 时钟
    RCC->APB2ENR |= (1 << 14) | (1 << 2);
    
    // PA9(TX) 推挽复用输出 50MHz
    GPIOA->CRH &= 0xFFFFFF0F;
    GPIOA->CRH |= 0x000000B0;
    
    // PA10(RX) 浮空输入
    GPIOA->CRH &= 0xFFFFF0FF;
    GPIOA->CRH |= 0x00000800;
    
    // 波特率：57600 @ 72MHz
    // USARTDIV = 72M/(16×57600) = 78.125
    USART1->BRR = (78 << 4) | 2;         // = 0x4E2
    
    USART1->CR1 = (1 << 13) | (1 << 3) | (1 << 2);  // UE+TE+RE
    USART1->CR2 = 0;                                  // 1停止位
}
```

验证：USARTDIV = 78 + 2/16 = 78.125，实际波特率 = 72M / (16×78.125) = **57600 ✓**

**知识点**：USART GPIO 复用配置、BRR 计算

#### （2）初始化 ADC 内部温度传感器（3分）

```c
void ADC_TempSensor_Init(void)
{
    // 使能 ADC1 时钟
    RCC->APB2ENR |= 1 << 9;
    RCC->APB2RSTR |= 1 << 9;               // 复位 ADC
    RCC->APB2RSTR &= ~(1 << 9);
    
    // 时钟分频：72MHz / 6 = 12MHz
    RCC->CFGR &= ~(3 << 14);
    RCC->CFGR |= 2 << 14;
    
    ADC1->CR1 &= ~(1 << 8);                 // SCAN=0
    ADC1->CR2 &= ~(1 << 1);                 // CONT=0: 单次
    ADC1->CR2 |= 7 << 17;                   // 软件触发
    ADC1->CR2 |= 1 << 20;                   // 外触发使能
    ADC1->CR2 |= 1 << 23;                   // TSVREFE: 使能温度传感器
    
    ADC1->SQR1 &= ~(0xF << 20);             // 序列长度=1
    ADC1->SQR3 &= 0xFFFFFFE0;
    ADC1->SQR3 |= 16;                        // 通道16（温度传感器）
    
    ADC1->SMPR1 &= ~(7 << 18);
    ADC1->SMPR1 |= 7 << 18;                  // 239.5周期
    
    ADC1->CR2 |= 1 << 0;                     // ADON: 使能 ADC
    // 校准
    ADC1->CR2 |= 1 << 3;                     // RSTCAL
    while (ADC1->CR2 & (1 << 3));
    ADC1->CR2 |= 1 << 2;                     // CAL
    while (ADC1->CR2 & (1 << 2));
}
```

**知识点**：ADC 时钟配置、温度传感器使能、规则序列、校准

#### （3）0.5s 定时采样 + USART1 发送 ASCII 码（4分）

```c
volatile uint8_t sample_flag = 0;
volatile uint16_t adc_result = 0;

// TIM2 初始化：0.5s 定时
void TIM2_Init(void)
{
    RCC->APB1ENR |= 1 << 0;                  // TIM2 时钟使能
    TIM2->PSC = 7199;                         // 72M/7200 = 10KHz
    TIM2->ARR = 4999;                         // 10KHz×5000 = 0.5s
    TIM2->DIER |= 1 << 0;                     // UIE
    NVIC->ISER[0] |= 1 << 28;                 // TIM2 IRQ28
    TIM2->CR1 |= 1;
}

// TIM2 中断：触发 ADC
void TIM2_IRQHandler(void)
{
    if (TIM2->SR & 0x0001) {
        TIM2->SR &= ~(1 << 0);
        ADC1->CR2 |= 1 << 22;                 // SWSTART
    }
}

// ADC 完成中断：读取结果
void ADC1_2_IRQHandler(void)
{
    if (ADC1->SR & (1 << 1)) {
        adc_result = ADC1->DR & 0xFFF;
        sample_flag = 1;
    }
}

// USART1 发送一个字节
void USART1_SendByte(uint8_t data)
{
    while (!(USART1->SR & (1 << 7)));
    USART1->DR = data;
}

// 将 12 位 ADC 值转为 3 个十六进制 ASCII 码发送
void Send_Hex_ASCII(uint16_t value)
{
    uint8_t nibbles[3] = {
        (value >> 8) & 0x0F,   // 高 4 位
        (value >> 4) & 0x0F,   // 中 4 位
        value & 0x0F            // 低 4 位
    };
    for (int i = 0; i < 3; i++) {
        if (nibbles[i] < 10)
            USART1_SendByte(nibbles[i] + 0x30);   // '0'~'9'
        else
            USART1_SendByte(nibbles[i] - 10 + 0x41); // 'A'~'F'
    }
}
```
