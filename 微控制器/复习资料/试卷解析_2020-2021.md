### 第1题
**题目**：下面定时器中，支持 PWM 互补输出的是（  ）。

A．TIM2　　B．TIM4　　C．TIM6　　D．TIM8

**答案**：**D（TIM8）**

**解析**：TIM1 和 TIM8 是**高级定时器**，支持 PWM 互补输出、死区插入等功能。TIM2/3/4/5 是通用定时器，TIM6/7 是基本定时器。

**知识点**：STM32 定时器分类——高级(TIM1,TIM8)、通用(TIM2~TIM5)、基本(TIM6,TIM7)

C．CONTROL[0]=1，CONTROL[1]=0

## 四、简答题（30分，每题6分）

### 第1题：中断优先级配置

**题目**：将47号外部中断设置为抢占2级：响应3级。

**答案**：
```c
SCB->AIRCR &= 0xF8FF;
SCB->AIRCR |= 0x05FA0500;       // 第5组（抢占3位+响应1位）
NVIC->ISER[1] |= 1 << 15;       // 47-32=15
NVIC->IPR[11] &= 0x00FFFFFF;
NVIC->IPR[11] |= 0xB0000000;    // 高8位=0xB0
```

**解析**：47号中断→ISER[1] bit15，IPR[11]（47/4=11，偏移(47%4)×8+4=28位）。分组5下，0xB0=10110000B，高4位[7:4]=1011。

**知识点**：NVIC中断使能与优先级配置、IPR位计算

---

### 第2题：中断退出与出栈

**题目**：LR=0xFFFFFFF1，某个中断活跃，中断退出后工作模式和特权级别？SP=0x20001000，出栈后R1、R2值？

**存储器数据**：

| SRAM地址 | 数据 |
|:--------:|:----:|
| 0x2000100C | 0x66666666 |
| 0x20001008 | 0x55555555 |
| 0x20001004 | 0x44444444 |
| 0x20001000 | 0x33333333 |

**答案**：
- 中断退出后为**处理者模式(Handler Mode)**，**特权级别**
- R1 = **0x44444444**
- R2 = **0x55555555**

**解析**：LR=0xFFFFFFF1表示返回Handler Mode。出栈8寄存器顺序：R0,R1,R2,R3,R12,LR,PC,xPSR。SP=0x20001000→R0=0x33333333→SP+4→R1=0x44444444→SP+4→R2=0x55555555。

**知识点**：CM3异常返回、自动压栈/出栈顺序

---

### 第3题：位带操作（Bit-banding）

**题目**：TIM2_CR1=0x40000000，TIM2_DIER=0x4000000C，TIM2_SR=0x40000010。向0x4200001C、0x42000180写1的作用？溢出时读0x42000000、0x42000200的值？

**答案**：
1. 0x4200001C → TIM2_CR1的bit8置1（ARPEn，ARR装入缓冲器）
2. 0x42000180 → TIM2_DIER的bit0置1（UIE，允许更新中断）
3. 溢出时：0x42000000→0（CEN清零），0x42000200→1（UIF置位）

**解析**：位带公式AliasAddr=0x42000000+byte_offset×32+bit×4。0x42000180对应TIM2_DIER的bit0✓。0x42000000对应CR1的bit0(CEN)，溢出自动清零。0x42000200对应SR的bit0(UIF)，溢出置位。

**知识点**：位带别名地址计算、TIM2控制/状态寄存器

### 第4题：定时器时钟与溢出配置

**题目**：SYSCLK=56MHz，AHB=56MHz，APB1=14MHz，TIM3的CK_INT=？实现300ms定时，PSC和ARR=？

**答案**：
- CK_INT = **28MHz**（APB1预分频=4≠1→TIM3CLK=2×PCLK1=28MHz）
- 方案一：PSC=2799，ARR=3000
- 方案二：PSC=27999，ARR=300

**解析**：定时周期=(PSC+1)×(ARR+1)/CK_INT。方案一：(2800×3001)/28M≈0.3s。

**知识点**：PSC/ARR定时计算

### 第5题：时钟配置与串口波特率

**题目**：HSE=16MHz，RCC->CFGR=0x000B6402，USART1波特率57600，求PCLK2、USARTDIV、USART_BRR？

**答案**：
- **PCLK2=16MHz**
- **USARTDIV=17.4**
- **USART_BRR=0x116**

**解析**：由CFGR得PLL输出32MHz=SYSCLK，AHB不分频=32MHz，APB2预分频=2→PCLK2=16MHz。USARTDIV=16M/(16×57600)=17.4。BRR=(17<<4)|6=0x116。

**知识点**：RCC时钟链、USART波特率计算

## 五、编程设计题（15分）

### 题目概述

利用ADC1采样监测内部电压，数码管显示(1位整数+1位小数)。APB2=72MHz，规则通道、软件触发、单次转换，ADC时钟=12MHz，采样周期=239.5周期，数据右对齐。PB0-PB7段选，PC0-PC1位选。TIM2每隔1秒采集十次取平均值。

#### （1）GPIO_init函数（3分）

```c
void GPIO_init()
{
    RCC->APB2ENR |= 1 << 3;          // PORTB时钟
    GPIOB->CRL &= 0x00000000;
    GPIOB->CRL |= 0x33333333;        // PB0~PB7推挽输出
    
    RCC->APB2ENR |= 1 << 4;          // PORTC时钟
    GPIOC->CRL &= 0xFFFFFF00;
    GPIOC->CRL |= 0x33;              // PC0、PC1推挽输出
}
```

**知识点**：RCC-APB2ENR、GPIO CRL配置

#### （2）ADC_init函数（5分）

```c
void ADC_init()
{
    RCC->APB2ENR |= 1 << 9;          // ADC1时钟使能
    RCC->APB2RSTR |= 1 << 9;
    RCC->APB2RSTR &= ~(1 << 9);
    
    RCC->CFGR &= ~(3 << 14);
    RCC->CFGR |= 2 << 14;            // 72/6=12MHz
    
    ADC1->CR1 &= 0xF0FEFF;           // 独立非扫描模式
    ADC1->CR2 &= ~(1 << 1);          // 单次转换
    ADC1->CR2 |= 7 << 17;            // 软件触发
    ADC1->CR2 |= 1 << 20;            // 外触发使能
    ADC1->CR2 &= ~(1 << 11);         // 右对齐
    
    ADC1->SQR1 &= ~(0xF << 20);      // 1个转换
    ADC1->SQR3 &= 0xFFFFFFE0;
    ADC1->SQR3 |= 0x11;              // 通道17（内部温度）
    
    ADC1->SMPR2 |= 7 << 21;          // 239.5周期
    
    ADC1->CR2 |= 1 << 0;             // ADON
    ADC1->CR2 |= 1 << 3;             // RSTCAL
    while (ADC1->CR2 & (1 << 3));
    ADC1->CR2 |= 1 << 2;             // CAL
    while (ADC1->CR2 & (1 << 2));
}
```

**知识点**：ADC时钟分频、模式配置、规则序列、采样周期、校准

#### （3）TIM2_init和TIM2_IRQHandler（4分）

```c
void TIM2_init()
{
    Stm32_Clock_Init(9);
    RCC->CFGR = 0x00000400;
    delay_init(72);
    GPIO_init();
    ADC_init();
    RCC->APB1ENR |= 1 << 0;          // TIM2时钟
    TIM2->ARR = 10000;               // 1秒定时
    TIM2->PSC = 7199;                // 72M/7200=10KHz
    TIM2->DIER |= 1 << 0;            // UIE
    TIM2->DIER |= 1 << 6;            // 触发中断使能
    TIM2->CR1 |= 0x01;
}

void TIM2_IRQHandler(void)
{
    if (TIM2->SR & 0x0001) {
        flag = true;
        TIM2->SR &= ~(1 << 0);
    }
}
```

**主程序采样逻辑**：
```c
while (1) {
    if (flag) {
        flag = false;
        vol = 0;
        for (count = 0; count < 10; count++) {
            ADC1->CR2 |= 1 << 22;    // SWSTART
            while (!(ADC1->SR & 1 << 1));
            vol += ((ADC1->DR) & 0xFFF) * 3.3 / 4096;
        }
        vol /= 10;
    }
}
```

**知识点**：TIM2定时器配置、中断服务函数、ADC触发与等待

                while (!(ADC1->SR & 1 << 1));
                vol += ((ADC1->DR) & 0xFFF) * 3.3 / 4096;
            }
            vol /= 10;
            
            a = (int)vol;                     // 整数部分
            b = (int)((vol - a) * 10 + 0.5);  // 小数部分（四舍五入）
            
            GPIOB->ODR = word[a];
            GPIOC->ODR = 2;          // 位选PC1
            Delay_ms(20);
            GPIOB->ODR = word[b];
            GPIOC->ODR = 1;          // 位选PC0
            Delay_ms(20);
        }
    }
}
