## 复习策略建议

### 按题型

| 题型 | 策略 | 目标 |
|:----:|:----|:----:|
| **选择题** | 掌握每个寄存器功能、外设基本特性 | 不丢分 |
| **填空题** | 熟练计算补码/BCD/地址/频率/电压 | 必拿满分 |
| **判断题** | 关注"所有/总是/任何"等绝对化表述 | 15题错≤3 |
| **简答题** | 掌握位带公式、USART_BRR计算、PSC/ARR计算、中断配置 | 争取满分 |
| **编程题** | 背熟GPIO_init / ADC_init / TIM_init 三段式模板 | 10/15分 |

### 按优先级

**第一梯队（每题必练到肌肉记忆）**：
1. 补码 / BCD / 进制转换
2. 定时器溢出时间 T = (PSC+1)×(ARR+1)/f
3. USART_BRR = DIV_Integer<<4 | DIV_Fraction×16
4. 位带别名地址 = 基址 + byte_offset×32 + bit×4
5. ADC 电压 = DR_VALUE × Vref / 4096（右对齐）
6. 自动压栈顺序：R0,R1,R2,R3,R12,LR,PC,xPSR

**第二梯队（理解+会推导）**：
1. AIRCR 分组计算（抢占位数+响应位数）
2. 时钟树推导（SYSCLK→HCLK→PCLK1/2→TIMCLK）
3. AFIO->EXTICR[ ] 端口映射
4. CM3 存储器映射区域
5. 小端/大端字节序

**第三梯队（2023-2024新增，重点关注）**：
1. LiteOS 任务创建流程（LOS_TaskCreate + TSK_INIT_PARAM_S）
2. 信号量操作（LOS_SemCreate / Pend / Post）
3. IEEE 754 单精度浮点数转换
