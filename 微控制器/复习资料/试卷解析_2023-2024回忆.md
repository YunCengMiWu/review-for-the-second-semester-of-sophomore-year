### 三、LiteOS 新内容（关键！）

| 回忆内容 | 解析 |
|---------|------|
| **信号量（semaphore）** 是任务间通信机制 | LiteOS 提供二值/计数信号量实现同步与互斥 |
| **任务创建函数**: `LOS_TaskCreate()` | 任务创建与删除是LiteOS基础 |
| **任务参数结构体**: `TSK_INIT_PARAM_S` | 包含优先级、栈大小、入口函数等 |
| **任务优先级**: 数值越小优先级越高 | 与CM3中断优先级规则一致 |
| **示例代码**: `CreatTest1Task()` → `LOS_TaskCreate(&Test1Task_Handle, &task_init_param)` | 任务创建标准流程 |
| **usTaskPrio=5, uwStackSize=1024, pfnTaskEntry=Test1Task** | 典型任务配置 |
| **CM3支持中断嵌套，高优先级抢占低优先级** | 与LiteOS任务抢占对比 |

## LiteOS 核心知识点速记

```c
// 1. 系统启动
LOS_KernelInit();     // 内核初始化
LOS_Start();          // 启动系统

// 2. 任务创建流程
TSK_INIT_PARAM_S task_init_param;
task_init_param.usTaskPrio = 5;       // 优先级（数值小=优先级高）
task_init_param.pcName = "Task1";      // 任务名
task_init_param.pfnTaskEntry = Task1;  // 入口函数
task_init_param.uwStackSize = 1024;    // 栈大小
LOS_TaskCreate(&TaskHandle, &task_init_param);  // 创建任务

// 3. 任务状态
// 就绪态 → 运行态 → 阻塞态 → 就绪态（循环）
// LOS_TaskResume() / LOS_TaskSuspend() / LOS_TaskDelete()

// 4. 信号量
UINT32 LOS_SemCreate(UINT16 count, UINT32 *semHandle);   // 创建计数信号量
UINT32 LOS_BinarySemCreate(UINT32 *semHandle);            // 创建二值信号量
UINT32 LOS_SemPend(UINT32 semHandle, UINT32 timeout);    // 获取（P操作）
UINT32 LOS_SemPost(UINT32 semHandle);                     // 释放（V操作）

// 5. 消息队列
UINT32 LOS_QueueCreate(...);   // 队列创建
UINT32 LOS_QueueRead(...);     // 读队列
UINT32 LOS_QueueWrite(...);    // 写队列
```
