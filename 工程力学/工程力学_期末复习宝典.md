## 📖 第2章 静力学基本知识与物体的受力分析

### 一、变形固体的基本假设

工程力学研究的对象是**变形固体**，在外力作用下都会发生变形。为简化分析，作如下假设：

| 假设 | 内容 | 意义 |
|------|------|------|
| **连续性假设** | 物体体积内毫无空隙地充满物质 | 可用连续函数描述 |
| **均匀性假设** | 物体内任何部分力学性能相同 | 材料常数处处相同 |
| **各向同性假设** | 物体各方向力学性能相同 | 材料常数与方向无关 |
| **小变形假设** | 变形远小于构件原始尺寸 | 按变形前尺寸列平衡方程 |
| **线弹性假设** | 外力与弹性变形成正比 | 适用胡克定律 |

### 二、基本概念

- **力**：物体间相互的机械作用
- **力的三要素**：大小、方向、作用点（对刚体退化为：大小、方向、作用线）
- **平衡**：物体相对于惯性参考系保持静止或匀速直线运动
- **力系**：同时作用于物体上的一群力
- **等效力系**：作用效应相同的两个力系
- **合力与分力**：一个力等效代替原力系→合力；原力系中各力→分力

### 三、静力学五条基本公理

| 公理 | 内容 |
|------|------|
| **①力的平行四边形法则** | 作用于同一点的两力合成，合力矢等于两分力矢的矢量和 |
| **②二力平衡公理** | 作用于刚体的二力平衡⇔大小相等、方向相反、作用线共线 |
| **③作用与反作用定律** | 两物体间相互作用力，大小相等、方向相反、沿同一直线，分别作用于两物体 |
| **④加减平衡力系公理** | 在刚体上增加或减去平衡力系，不改变原力系作用效应 |
| **⑤刚化公理** | 变形体在某一力系下平衡，刚化后平衡状态不变 |

**两个推论**：
- **力的可传性**：力可沿作用线滑移至刚体内任一点，不改变效应
- **三力平衡汇交定理**：刚体在不平行三力下平衡⇔三力作用线汇交于一点且共面

### 四、约束与约束反力

| 约束类型 | 反力特点 |
|----------|----------|
| **柔索约束** | 沿柔索中心线，只能受拉 |
| **光滑接触面** | 沿接触面公法线，只能受压 |
| **光滑圆柱铰链** | 过销钉中心，方向不定→用两正交分力表示 |
| **链杆约束** | 沿链杆中心线，可拉可压 |
| **固定铰支座** | 同圆柱铰链，用两正交分力表示 |
| **可动铰支座** | 垂直于支承面 |
| **固定端支座** | 限制移动和转动→用三个分量表示 |

### 五、受力分析—画受力图步骤

1. **取分离体**—解除约束，单独画出
2. **画主动力**—已知力（荷载、重力等）
3. **画约束反力**—根据约束类型


### 📝 【考点例题2-1】画三铰刚架受力图

**题目**：自重不计的三铰刚架，试分别画出构件AC、BC和整体的受力图。

**解要点**：
- BC为**二力构件**，受力沿BC连线
- AC受主动力F、C处BC给的反力、A处固定铰支座反力（用FAx、FAy表示）
- 整体受力：主动力F + A处支座反力 + B处支座反力

## 📖 第3章 力系的简化

### 一、力在轴上的投影

$$F_n = F \cdot \cos\alpha$$

- 投影是**代数量**
- 沿直角坐标轴：$F_x = F\cos\alpha$, $F_y = F\sin\alpha$, 合力 $F = F_x i + F_y j$

### 二、力对点之矩

$$M_O(F) = \pm F \cdot h$$

- 逆时针为**正**，顺时针为**负**
- 矩心、力臂是要素
- 力通过矩心时力矩为零

**合力矩定理**：$M_O(F_R) = \sum M_O(F_i)$

### 三、力偶及其性质

**力偶**：等值、反向、不共线的平行力 $(F, F')$

**力偶矩**：$M(F, F') = \pm F \cdot d$

**力偶性质**：
1. 不能合成为一个力，不能与一个力平衡
2. 力偶对任一点的矩恒等于力偶矩，与矩心位置无关
3. 力偶可在其作用面内任意移转而不改变效应
4. 可同时改变力的大小和力偶臂长度，保持力偶矩不变

### 四、力的平移定理

> 作用于刚体上某点的力可平移到任一点，但须同时附加一个力偶，其矩等于原力对平移点之矩。

$$M = M_B(F)$$

### 五、平面一般力系的简化

**简化结果**：一个主矢量 $F_R'$ + 一个主矩 $M_O$

$$F_R' = \sum F_i, \quad M_O = \sum M_O(F_i)$$

**四种情形**：

| 条件 | 结果 |
|------|------|
| $F_R' = 0, M_O \neq 0$ | 合力偶 |
| $F_R' \neq 0, M_O = 0$ | 合力（过O点） |
| $F_R' \neq 0, M_O \neq 0$ | 可进一步简化为一个合力 |
| $F_R' = 0, M_O = 0$ | 平衡力系 |

### 六、分布荷载的合力

- **合力大小** = 荷载图形的面积
- **合力方向** = 与原荷载方向相同
- **合力作用线** = 通过荷载图形形心

### 📝 【考点例题3-1】力系简化计算

**题目**：平面一般力系，$F_1 = 130N$, $F_2 = 100\sqrt{2}N$, $F_3 = 50N$, $M = 500N\cdot m$，求合成的结果。

**解题思路**：
1. 建立坐标系，计算各力在x、y轴上的投影
2. 计算 $F_{Rx}' = \sum F_{ix}$, $F_{Ry}' = \sum F_{iy}$
3. 计算 $F_R' = \sqrt{F_{Rx}'^2 + F_{Ry}'^2}$
4. 计算主矩 $M_O = \sum M_O(F_i)$
5. 判断简化结果类型，若需进一步简化则求合力作用线位置

## 📖 第4章 力系的平衡

### 一、平面一般力系的平衡方程

**基本形式**（一矩式）：
$$\sum F_{ix} = 0,\quad \sum F_{iy} = 0,\quad \sum M_O(F_i) = 0$$

**二矩式**：
$$\sum F_{ix} = 0,\quad \sum M_A(F_i) = 0,\quad \sum M_B(F_i) = 0$$
（AB连线不垂直x轴）

**三矩式**：
$$\sum M_A(F_i) = 0,\quad \sum M_B(F_i) = 0,\quad \sum M_C(F_i) = 0$$
（A、B、C三点不共线）

### 二、特殊力系的平衡方程

| 力系类型 | 有效方程数 | 平衡方程 |
|----------|-----------|----------|
| 平面汇交力系 | 2 | $\sum F_x = 0, \sum F_y = 0$ |
| 平面平行力系 | 2 | $\sum F_y = 0, \sum M_O = 0$ |
| 平面力偶系 | 1 | $\sum M_i = 0$ |

### 三、物体系统的平衡

**求解策略**：
- **有主次之分**：先分析次要部分（附属部分），后分析主要部分（基本部分）
- **无主次之分**：灵活选取研究对象，利用整体和局部结合
- **运动机构**：沿运动传动顺序逐个构件分析

### 📝 【考点例题4-1】多跨刚架支座反力

**题目**：多跨刚架受平面力系作用，已知 $q$、$l$、$F = \frac{3}{2}ql$、$M = ql^2/2$，求A、D处约束反力。

**解**：
1. 先分析次要部分BD → 求$F_D$
2. 再分析主要部分AB → 求$F_{Ax}$、$F_{Ay}$、$M_A$

## 📖 第5章 杆件的内力分析与内力图

### 一、杆件变形的基本形式

| 变形形式 | 荷载特征 | 内力 |
|----------|----------|------|
| 轴向拉伸/压缩 | 沿轴线方向的力 | 轴力 $F_N$ |
| 剪切 | 垂直于轴线的横向力 | 剪力 $F_S$ |
| 扭转 | 力偶矩矢沿轴线方向 | 扭矩 $M_T$ |
| 弯曲 | 横向力或力偶 | 弯矩 $M$ |

### 二、截面法求内力（"截、取、画、平"）

1. **截** — 假想截面截开
2. **取** — 取一部分为分离体
3. **画** — 画受力图（含内力）
4. **平** — 列平衡方程求内力

### 三、轴力与轴力图

**轴力正负号**：拉力为正，压力为负

### 四、扭矩与扭矩图

**外力偶矩计算**：$M_e = 9.55\frac{P}{n}$ （$P$单位kW，$n$单位r/min）

**扭矩正负号**：右手螺旋法则，大拇指指向外法线方向为正

### 五、梁的内力

**剪力正负号**：使微段顺时针转动趋势为**正**
**弯矩正负号**：使微段向下凸出为**正**

**直接法**：
- 剪力 = 截面一侧所有竖向外力的代数和（左上右下为正）
- 弯矩 = 截面一侧所有外力对截面形心力矩的代数和（向上力产生正弯矩）

### 六、弯矩、剪力与荷载集度的微分关系

$$\frac{dF_S(x)}{dx} = q(x),\quad \frac{dM(x)}{dx} = F_S(x),\quad \frac{d^2M(x)}{dx^2} = q(x)$$

**几何意义**：
- 剪力图的斜率 = 荷载集度
- 弯矩图的斜率 = 剪力
- 弯矩图的凹凸性由荷载集度方向决定

### 📝 【考点例题5-1】绘制梁的内力图

**题目**：外伸梁受集中力F和均布荷载q作用，用微分关系法作剪力图和弯矩图。

**解题步骤**：
1. 求支座反力
2. 确定分段（集中力、集中力偶、分布荷载端点为分界点）
3. 分段绘制：判断形状 → 计算控制截面值 → 连线

## 📖 第6章 平面图形的几何性质

### 一、静矩与形心

**静矩（面积矩）**：
$$S_y = \int_A z \, dA,\quad S_z = \int_A y \, dA$$

**形心与静矩关系**：
$$y_c = \frac{S_z}{A} = \frac{\sum A_i y_{ci}}{\sum A_i},\quad z_c = \frac{S_y}{A} = \frac{\sum A_i z_{ci}}{\sum A_i}$$

**重要结论**：
- 图形对形心轴的静矩**恒为零**
- 某轴静矩为零 → 该轴为形心轴
- 对称轴必为形心轴

### 二、惯性矩与惯性积

**定义**：
$$I_y = \int_A z^2 dA,\quad I_z = \int_A y^2 dA,\quad I_{yz} = \int_A yz \, dA$$

**极惯性矩**：$I_p = I_y + I_z$

**性质**：
- 惯性矩恒为正，惯性积可正可负可为零
- 有一轴为对称轴 → 惯性积为零

### 三、常用截面惯性矩

| 截面 | $I_z$ | $I_y$ | $W_z$ |
|------|-------|-------|-------|
| 矩形 $b\times h$ | $bh^3/12$ | $hb^3/12$ | $bh^2/6$ |
| 圆形 $d$ | $\pi d^4/64$ | $\pi d^4/64$ | $\pi d^3/32$ |
| 圆环 $D,d$ | $\frac{\pi D^4}{64}(1-\alpha^4)$ | 相同 | $\frac{\pi D^3}{16}(1-\alpha^4)$ |
| 箱形 | $\frac{bh^3}{12} - \frac{b_1h_1^3}{12}$ | $\frac{hb^3}{12} - \frac{h_1b_1^3}{12}$ | — |

### 四、平行移轴公式

$$I_y = I_{y_c} + a^2A,\quad I_z = I_{z_c} + b^2A,\quad I_{yz} = I_{y_c z_c} + abA$$

其中 $a,b$ 是形心在新坐标系中的坐标

**核心结论**：在所有平行轴中，形心轴的惯性矩**最小**

### 五、回转半径

$$i_z = \sqrt{\frac{I_z}{A}},\quad i_y = \sqrt{\frac{I_y}{A}}$$

- 矩形：$i_z = h/(2\sqrt{3})$, $i_y = b/(2\sqrt{3})$
- 圆形：$i = d/4$

### 📝 【考点例题6-1】T形截面形心与惯性矩

**题目**：T形截面（翼缘 $0.6m \times 0.12m$，腹板 $0.4m \times 0.2m$），求形心位置和对形心轴z的惯性矩。

**解**：
1. 形心：$y_c = \frac{A_I y_{cI} + A_{II} y_{cII}}{A_I + A_{II}} = 0.197m$
2. 惯性矩：用平行移轴公式分别计算两部分的 $I_z$ 再叠加

## 📖 第7章 应力及强度计算

### 一、应力概念

- **正应力 $\sigma$** — 垂直于截面的应力分量
- **切应力 $\tau$** — 平行于截面的应力分量
- 单位：Pa（$N/m^2$），常用MPa

### 二、轴向拉压杆的应力与强度

**正应力公式**：$\sigma = \frac{F_N}{A}$

**强度条件**：$\sigma_{\max} = \left(\frac{F_N}{A}\right)_{\max} \leq [\sigma]$

**三类问题**：
1. **强度校核**：$\sigma_{\max} \leq [\sigma]$
2. **设计截面**：$A \geq \frac{F_{N\max}}{[\sigma]}$
3. **确定许用荷载**：$[F_N] \leq A[\sigma]$

### 三、材料力学性能

**低碳钢拉伸的四个阶段**：
1. **弹性阶段**（$oa'$）— $E = \tan\alpha$，$\sigma_p$比例极限
2. **屈服阶段**（$a'c$）— $\sigma_s$屈服极限
3. **强化阶段**（$cd$）— $\sigma_b$强度极限
4. **局部变形阶段**（$de$）— 颈缩

**两个塑性指标**：
- 延伸率 $\delta = \frac{l_1 - l}{l} \times 100\%$，$\delta \geq 5\%$为塑性材料
- 断面收缩率 $\psi = \frac{A - A_1}{A} \times 100\%$

**两类材料比较**：

| 性质 | 塑性材料 | 脆性材料 |
|------|----------|----------|
| 延伸率 | $\delta \geq 5\%$ | $\delta < 5\%$ |
| 极限应力 | $\sigma_s$（屈服） | $\sigma_b$（断裂） |
| 抗压vs抗拉 | 相近 | 抗压 > 抗拉 |
| 断裂前变形 | 大 | 小 |

### 四、连接件实用计算

**剪切强度**：
$$\tau_j = \frac{F_S}{A_j} \leq [\tau_j]$$

**挤压强度**：
$$\sigma_{bs} = \frac{F_{bs}}{A_{bs}} \leq [\sigma_{bs}]$$

### 五、圆轴扭转应力

**切应力分布**：$\tau_\rho = \frac{M_T \rho}{I_p}$

**最大切应力**：$\tau_{\max} = \frac{M_T}{W_p}$，$W_p = \frac{I_p}{\rho_{\max}}$

**扭转强度条件**：$\tau_{\max} = \frac{M_{T\max}}{W_p} \leq [\tau]$

### 六、梁的正应力

**纯弯曲正应力公式**：
$$\sigma = \frac{My}{I_z},\quad \sigma_{\max} = \frac{M}{W_z}$$

**抗弯截面模量**：
- 矩形：$W_z = bh^2/6$
- 圆形：$W_z = \pi d^3/32$

### 七、梁的切应力

**矩形截面**：$\tau = \frac{F_S S_z^*}{b I_z}$，$\tau_{\max} = \frac{3F_S}{2A}$

**工字形截面**：$\tau_{\max} = \frac{F_S}{d \cdot (I_z/S_{z\max})}$

### 八、梁的强度条件

**正应力强度**：$\sigma_{\max} = \frac{M_{\max}}{W_z} \leq [\sigma]$

**切应力强度**：$\tau_{\max} = \frac{F_{S\max}S_{z\max}}{bI_z} \leq [\tau]$

> 细长梁以正应力强度控制为主

### 📝 【考点例题7-1】拉压杆强度校核+许用荷载

**题目**：三角托架，AB钢杆 $A_1=600mm^2$, $[\sigma_1]=160MPa$；BC木杆 $A_2=10^4mm^2$, $[\sigma_2]=7MPa$，$F=10kN$，①校核强度；②求许用荷载[F]

**解**：节点法求轴力 $F_{N1}=2F=20kN$（拉），$F_{N2}=-\sqrt{3}F=-17.3kN$（压）
- $\sigma_1=33.3MPa < 160MPa$ ✓
- $\sigma_2=1.73MPa < 7MPa$ ✓
- [F]由杆2控制：$[F] = 40.4kN$

### 📝 【考点例题7-2】梁的强度校核（T形截面）

**题目**：T形截面铸铁梁，$[\sigma_t]=45MPa$, $[\sigma_c]=175MPa$，$I_z=5.73\times10^6mm^4$，$y_1=72mm$, $y_2=38mm$，校核强度。

**注意**：脆性材料需分别校核拉应力和压应力，且危险截面不一定是弯矩最大的截面（因中性轴不对称，需比较 $M\cdot y$ 的乘积）

## 📖 第8章 变形及刚度计算

### 一、轴向拉压杆的变形

**胡克定律**：
$$\Delta l = \frac{F_N \cdot l}{EA}$$

**线应变**：$\varepsilon = \frac{\Delta l}{l}$，胡克定律 $\sigma = E\varepsilon$

**横向变形**：$\varepsilon' = -\mu\varepsilon$（$\mu$为泊松比）

### 二、圆轴扭转变形

**扭转角**：$\varphi = \frac{M_T \cdot l}{GI_p}$

**单位长度扭转角**：$\theta = \frac{M_T}{GI_p}$

**刚度条件**：$\theta_{\max} = \frac{M_T}{GI_p} \times \frac{180}{\pi} \leq [\theta]$（°/m）

### 三、梁的变形

**挠曲线近似微分方程**：
$$y'' = -\frac{M(x)}{EI}$$

**积分法**：
$$\theta = y' = -\int\frac{M(x)}{EI}dx + C$$
$$y = -\iint\frac{M(x)}{EI}dx\,dx + Cx + D$$

**边界条件**：
- 固定端：$y=0$, $\theta=0$
- 铰支座：$y=0$

**连续光滑条件**：分段处 $y_1 = y_2$, $\theta_1 = \theta_2$

### 四、常见梁的挠度和转角

| 梁型 | 最大挠度 | 端转角 |
|------|----------|--------|
| 悬臂梁+端部F | $y_{\max} = \frac{Fl^3}{3EI}$ | $\theta_B = \frac{Fl^2}{2EI}$ |
| 悬臂梁+均布q | $y_{\max} = \frac{ql^4}{8EI}$ | $\theta_B = \frac{ql^3}{6EI}$ |
| 简支梁+跨中F | $y_{\max} = \frac{Fl^3}{48EI}$ | $\theta_A = \frac{Fl^2}{16EI}$ |
| 简支梁+均布q | $y_{\max} = \frac{5ql^4}{384EI}$ | $\theta_A = \frac{ql^3}{24EI}$ |

### 五、叠加法求变形

在线弹性和小变形条件下，多个荷载共同作用的变形等于各荷载单独作用变形的代数和。

### 六、简单超静定问题（力法）

**解题步骤**：
1. 列静力平衡方程
2. 建立变形协调条件
3. 利用物理关系（胡克定律）建立补充方程
4. 联立求解

### 📝 【考点例题8-1】悬臂梁变形计算

**题目**：悬臂梁自由端受集中力F和均布荷载q共同作用，求自由端挠度和转角。

**解**（叠加法）：
$$y_B = \frac{ql^4}{8EI} + \frac{Fl^3}{3EI}$$
$$\theta_B = \frac{ql^3}{6EI} + \frac{Fl^2}{2EI}$$

## 📖 第11章 压杆稳定

### 一、稳定性的概念

**理想压杆**：外力 < 临界力 → 稳定平衡；外力 = 临界力 → 临界状态；外力 > 临界力 → 失稳

### 二、欧拉公式

**两端铰支**：$F_{cr} = \frac{\pi^2 EI}{l^2}$

**一般形式**：$F_{cr} = \frac{\pi^2 EI}{(\mu l)^2}$

**长度系数** $\mu$：

| 约束条件 | $\mu$ |
|----------|-------|
| 两端铰支 | 1 |
| 一端固定一端自由 | 2 |
| 两端固定 | 0.5 |
| 一端固定一端铰支 | 0.7 |

**注意**：$I$取$I_{\min}$，即截面两个形心主惯性矩中较小的一个

### 三、临界应力与柔度

**临界应力**：$\sigma_{cr} = \frac{F_{cr}}{A} = \frac{\pi^2 E}{\lambda^2}$

**柔度（长细比）**：$\lambda = \frac{\mu l}{i}$，$i = \sqrt{\frac{I}{A}}$

### 四、欧拉公式适用范围

$$\lambda \geq \lambda_p = \pi\sqrt{\frac{E}{\sigma_p}}$$

- Q235钢：$\lambda_p \approx 102$
- 当 $\lambda < \lambda_p$ 时，用经验公式 $\sigma_{cr} = a - b\lambda$ 或抛物线公式

### 五、压杆分类

| 类型 | 条件 | 临界应力公式 |
|------|------|-------------|
| 细长杆 | $\lambda \geq \lambda_p$ | $\sigma_{cr} = \pi^2 E/\lambda^2$ |
| 中长杆 | $\lambda_s \leq \lambda < \lambda_p$ | $\sigma_{cr} = a - b\lambda$ |
| 粗短杆 | $\lambda < \lambda_s$ | $\sigma_{cr} = \sigma_s$ |

### 六、稳定计算

**稳定条件**：
$$n = \frac{F_{cr}}{F_N} \geq n_{st}$$

**安全因素法**：
$$F_N \leq \frac{F_{cr}}{n_{st}}$$

### 📝 【考点例题11-1】细长压杆临界力计算

**题目**：3号钢细长杆，长1m，矩形截面 $8mm \times 20mm$，两端铰支，$E=210GPa$，$\sigma_s=240MPa$，求临界荷载并与屈服荷载比较。

**解**：
$$I_{\min} = \frac{20 \times 8^3}{12} = 853.3mm^4$$
$$F_{cr} = \frac{\pi^2 \times 210\times 10^3 \times 853.3}{1000^2} = 1.768kN$$
$$F_s = A\sigma_s = 160 \times 240 = 38.4kN$$
$$F_{cr}:F_s \approx 1:22$$

> **结论**：稳定性控制细长压杆的承载能力，强度不起控制作用。

## 二、全题型例题详解（覆盖全部考点）

### 【题型1】受力图画法

**例题1-1**：试画出图示结构中AB梁的受力图。梁自重不计，A端为固定铰支座，B端为可动铰支座，梁上受集中力F和均布荷载q。

**解**：
1. 取AB为分离体
2. 主动力：集中力F（向下）、均布荷载q（向下）
3. 约束反力：A端 FAx（水平）、FAy（竖直）；B端 FB（垂直于支承面，竖直向上）

**例题1-2**：试画出三铰刚架的整体受力图及各部分受力图。

**解要点**：
- 整体：A端固定铰支座反力FAx、FAy；B端固定铰支座反力FBx、FBy；主动力F
- BC部分：二力构件，两端铰链反力沿BC连线
- AC部分：主动力F + C处FC（大小等于FB，方向相反）+ A处FAx、FAy

---

### 【题型2】平面力系的平衡问题

**例题2-1**：悬臂刚架受均布荷载q=10kN/m、集中力F=10kN、力偶M=8kN·m，求固定端A的约束反力。

**解**：
取刚架AB为研究对象：
$$\sum F_x = 0: F_{Ax} - F = 0 \Rightarrow F_{Ax} = 10kN$$
$$\sum F_y = 0: F_{Ay} - q \times 2 = 0 \Rightarrow F_{Ay} = 20kN$$
$$\sum M_A = 0: M_A + F \times 4 - q \times 2 \times 1 - M = 0 \Rightarrow M_A = -12kN\cdot m$$

**例题2-2**：多跨梁如图，已知q=10kN/m，M=20kN·m，求A处支座反力。

**解**：
1. 判断主次结构，先分析附属部分（BC段）
2. 再分析主要部分（AB段）
3. 联立求解得到A处三个反力分量

---

### 【题型3】画剪力图和弯矩图

**例题3-1**：外伸梁受荷载如图，用微分关系法绘制剪力图和弯矩图。

**题目条件**：AB段长2a受均布荷载q，BC段长a受集中力F=qa，C端有力偶M_e=qa^2

**解**：
1. 求支反力：$\sum M_A=0$, $\sum F_y=0$ 得 $F_A$, $F_B$
2. 分段：AB段（有分布荷载）、BC段（无分布荷载）
3. 剪力图：
   - AB段：斜直线（$q$为常数），两端控制值
   - BC段：水平线（$q=0$）
4. 弯矩图：
   - AB段：二次抛物线（$q$为常数，下凸），需计算极值位置
   - BC段：斜直线

**关键控制点**：集中力作用处剪力突变、集中力偶作用处弯矩突变

**例题3-2**：简支梁受集中力F，作剪力图和弯矩图。

**解**：
$$F_A = \frac{Fb}{l}, \quad F_B = \frac{Fa}{l}$$
- AC段：$F_S = \frac{Fb}{l}$（常数），$M = \frac{Fb}{l}x_1$（线性）
- CB段：$F_S = -\frac{Fa}{l}$（常数），$M = \frac{Fa}{l}(l-x_2)$（线性）
- 集中力F作用处：剪力突变 $F \times b/l \to -F \times a/l$，弯矩取峰值 $M_{\max} = \frac{Fab}{l}$

---

### 【题型4】组合截面的几何性质

**例题4-1**：确定图示箱形截面的形心主轴位置，计算对形心轴的惯性矩。已知外尺寸$b \times h$，内尺寸$b_1 \times h_1$。

**解**：
由于对称性，形心在截面中心。
$$I_z = \frac{bh^3}{12} - \frac{b_1h_1^3}{12}, \quad I_y = \frac{hb^3}{12} - \frac{h_1b_1^3}{12}$$

**例题4-2**：T形截面，上翼缘$200mm \times 20mm$，下腹板$20mm \times 180mm$，求形心位置和对形心轴的惯性矩。

**解**：
1. 建立坐标系（以底边为参考轴）
2. 形心坐标：$y_c = \frac{A_1y_{c1} + A_2y_{c2}}{A_1 + A_2}$
3. 对形心轴惯性矩：平行移轴公式，$I_z = I_{zc}^{(1)} + a_1^2A_1 + I_{zc}^{(2)} + a_2^2A_2$

---

### 【题型5】拉压杆强度与变形

**例题5-1**：图示三角架，AB为钢杆$A_1=600mm^2$, $[\sigma_1]=160MPa$；AC为木杆$A_2=10^4mm^2$, $[\sigma_2]=7MPa$。$F=10kN$。
① 校核强度 ② 求许用荷载[F] ③ F=[F]时重新选择AB杆截面

**解**：
① 节点法求轴力→应力校核（见前文考点例题7-1）
② [F]受杆2控制：$[F] = \frac{A_2[\sigma_2]}{\sqrt{3}} = 40.4kN$
③ $A_1 \geq \frac{2[F]}{[\sigma_1]} = 505mm^2$

**例题5-2**：等直钢杆阶梯轴，各段轴力不同，$E=200GPa$，求总伸长量。

**解**：
$$\Delta l = \sum \frac{F_{Ni} \cdot l_i}{EA_i}$$
分段计算后叠加。

---

### 【题型6】梁的强度校核

**例题6-1**：矩形截面简支梁，$b \times h = 100mm \times 150mm$，受均布荷载$q=5kN/m$，跨长$l=4m$，$[\sigma]=10MPa$, $[\tau]=2.2MPa$，校核强度。

**解**：
1. 正应力强度：
$$M_{\max} = \frac{ql^2}{8} = 10kN\cdot m$$
$$W_z = \frac{bh^2}{6} = \frac{100 \times 150^2}{6} = 3.75 \times 10^5 mm^3$$
$$\sigma_{\max} = \frac{M_{\max}}{W_z} = 26.7MPa > [\sigma] = 10MPa \quad ❌$$
（不满足，需加大截面或减小荷载）

2. 切应力强度：
$$F_{S\max} = \frac{ql}{2} = 10kN$$
$$\tau_{\max} = \frac{3F_{S\max}}{2A} = 1.0MPa < [\tau] = 2.2MPa \quad ✓$$

**例题6-2**：工字钢梁强度校核（查型钢表计算）

I22a工字钢，$W_z=309cm^3$，$d=7.5mm$，$I_z/S_{z\max}=18.9cm$，$[\sigma]=170MPa$, $[\tau]=100MPa$。

$$\sigma_{\max} = \frac{M_{\max}}{W_z}, \quad \tau_{\max} = \frac{F_{S\max}}{d \cdot (I_z/S_{z\max})}$$

---

### 【题型7】压杆稳定

**例题7-1**：矩形截面压杆$b=50mm$, $h=100mm$, 长$l=3m$, 下端固定, 上端在xOy面内铰支, xOz面内自由, $E=200GPa$, $\sigma_p=265MPa$。求临界轴力。

**解**：
1. 计算柔度
   - xOy面：$\mu=0.5$, $i_z = h/\sqrt{12} = 28.87mm$, $\lambda_z = \mu l / i_z = 52$
   - xOz面：$\mu=2$, $i_y = b/\sqrt{12} = 14.43mm$, $\lambda_y = \mu l / i_y = 138.56$
2. 取大柔度 $\lambda_{\max} = 138.56 > \lambda_p = \pi\sqrt{E/\sigma_p} = 86.3$
3. 欧拉公式适用：
$$F_{cr} = \frac{\pi^2 E}{\lambda_y^2} \cdot A = \frac{\pi^2 \times 200 \times 10^3}{138.56^2} \times 5000 = 1540kN$$

**例题7-2**：三角支架，BC杆为10号工字钢，$E=200GPa$, $\sigma_p=200MPa$, $l_{AB}=1.5m$, $n_{st}=2.2$，由BC杆稳定性求许用荷载[F]。

**解**：
$$i_{\min}=15.2mm, A=1434.5mm^2, l_{BC}=\sqrt{2}\times 1.5 = 2.121m$$
$$\lambda = 2121/15.2 = 139.6 > \lambda_p = 99.3$$
$$F_{cr} = \frac{\pi^2 EA}{\lambda^2} = 145.2kN$$
$$[F_{BC}] = \frac{F_{cr}}{n_{st}} = 66kN$$
由节点平衡：$[F] = \frac{\sqrt{2}}{2} \times 66 = 46.7kN$

---

### 【题型8】叠加法求梁的变形

**例题8-1**：悬臂梁AB，长$l=2m$，$EI=常数$，在自由端受集中力$F=10kN$，同时全梁受均布荷载$q=5kN/m$。求自由端转角和挠度。

**解**（叠加法）：
$$\theta_B = \frac{Fl^2}{2EI} + \frac{ql^3}{6EI} = \frac{10 \times 4}{2EI} + \frac{5 \times 8}{6EI} = \frac{20}{EI} + \frac{6.67}{EI} = \frac{26.67}{EI}$$
$$y_B = \frac{Fl^3}{3EI} + \frac{ql^4}{8EI} = \frac{10 \times 8}{3EI} + \frac{5 \times 16}{8EI} = \frac{26.67}{EI} + \frac{10}{EI} = \frac{36.67}{EI}$$

**例题8-2**：简支梁跨中受集中力F，求跨中挠度和两端转角。

**解**（查表）：
$$y_{\max} = \frac{Fl^3}{48EI}, \quad \theta_A = -\theta_B = \frac{Fl^2}{16EI}$$

---

### 【题型9】超静定问题

**例题9-1**：两端固定的等直杆，在C点受轴向力F作用，AC=a，CB=b，求两端反力。

**解**：
1. 平衡方程：$F_A + F_B = F$
2. 变形协调：$\Delta l_{AC} + \Delta l_{CB} = 0$
3. 物理关系：$\frac{F_A a}{EA} - \frac{F_B b}{EA} = 0 \Rightarrow F_A a = F_B b$
4. 联立得：$F_A = \frac{Fb}{a+b}$, $F_B = \frac{Fa}{a+b}$

**例题9-2**：一端固定一端铰支梁受均布荷载q，求支座反力。

**解**：
1. 平衡方程有两个未知量（$R_A$, $R_B$, $M_A$）→ 一次超静定
2. 变形协调：$y_B = 0$
3. 查表叠加：$\frac{ql^4}{8EI} - \frac{R_B l^3}{3EI} = 0 \Rightarrow R_B = \frac{3ql}{8}$
4. 由平衡得：$R_A = \frac{5ql}{8}$, $M_A = \frac{ql^2}{8}$

---

### 【题型10】圆轴扭转

**例题10-1**：圆轴$d=80mm$, $G=80GPa$, $M_T=2kN\cdot m$, 长度$l=2m$, $[\theta]=0.8^\circ/m$。求最大切应力和扭转角，校核刚度。

**解**：
$$W_p = \frac{\pi d^3}{16} = 100.5 \times 10^3 mm^3$$
$$\tau_{\max} = \frac{M_T}{W_p} = 19.9MPa$$
$$I_p = \frac{\pi d^4}{32} = 4.02 \times 10^6 mm^4$$
$$\varphi = \frac{M_T l}{GI_p} = 0.0124rad$$
$$\theta_{\max} = \frac{M_T}{GI_p} \times \frac{180}{\pi} = 0.356^\circ/m < 0.8^\circ/m \quad ✓$$

## 核心公式速记卡

### 拉压
$$\sigma = \frac{F_N}{A},\quad \Delta l = \frac{F_N l}{EA},\quad \varepsilon = \frac{\Delta l}{l}$$

### 扭转
$$\tau_{\max} = \frac{M_T}{W_p},\quad \varphi = \frac{M_T l}{GI_p},\quad \theta = \frac{M_T}{GI_p}$$

### 弯曲
$$\sigma = \frac{My}{I_z},\quad \sigma_{\max} = \frac{M}{W_z},\quad y'' = -\frac{M(x)}{EI}$$

### 截面几何性质
$$S_z = A y_c,\quad I_z = \int_A y^2 dA,\quad I_y = I_{yc} + a^2A$$

### 压杆稳定
$$F_{cr} = \frac{\pi^2 EI}{(\mu l)^2},\quad \sigma_{cr} = \frac{\pi^2 E}{\lambda^2},\quad \lambda = \frac{\mu l}{i}$$
