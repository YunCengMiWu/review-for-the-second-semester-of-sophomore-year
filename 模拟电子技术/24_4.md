这是一道关于**稳压二极管（齐纳二极管）稳压电路**的经典计算题。我们需要求解限流电阻 $R$ 的取值范围，也就是求出 $R$ 的最大值 $R_{\max}$ 和最小值 $R_{\min}$。

首先，我们把题目中的已知条件一一列出并做好准备工作：

* **输入电压**：$U_I = 50\text{V}$，波动范围为 $\pm 10\%$
* 输入电压最小值：$U_{I\min} = 50 \times (1 - 10\%) = 45\text{V}$
* 输入电压最大值：$U_{I\max} = 50 \times (1 + 10\%) = 55\text{V}$


* **输出电压（稳压值）**：$U_O = U_Z = 18\text{V}$
* **稳压管最小稳定电流**：$I_{Z\min} = 5\text{mA}$
* **稳压管最大耗散功率**：$P_{ZM} = 0.54\text{W}$
* 由此可求出稳压管允许的最大电流：$I_{ZM} = \frac{P_{ZM}}{U_Z} = \frac{0.54\text{W}}{18\text{V}} = 0.03\text{A} = 30\text{mA}$


* **负载电阻范围**：$R_L = 1 \sim 2\text{k}\Omega$
* 负载电流最大值：$I_{L\max} = \frac{U_O}{R_{L\min}} = \frac{18\text{V}}{1\text{k}\Omega} = 18\text{mA}$
* 负载电流最小值：$I_{L\min} = \frac{U_O}{R_{L\max}} = \frac{18\text{V}}{2\text{k}\Omega} = 9\text{mA}$



---

### 一、 求解限流电阻的最大值 $R_{\max}$

为了保证稳压管能正常工作，即使在最极端、最艰难的条件下，流过稳压管的电流也绝对不能低于它的最小稳定电流 $I_{Z\min}$。

**最艰难的条件**是指：**输入电压最低**（供电不足），同时**负载分走的电流最大**（抢占资源）。

在这个临界状态下，总电流 $I_R$ 为：


$$I_{R} = I_{Z\min} + I_{L\max} = 5\text{mA} + 18\text{mA} = 23\text{mA}$$

此时，电阻两端的电压差也是最小的（$U_{I\min} - U_Z$）。根据欧姆定律，限流电阻的最大阻值为：


$$R_{\max} = \frac{U_{I\min} - U_Z}{I_{Z\min} + I_{L\max}} = \frac{45\text{V} - 18\text{V}}{23\text{mA}} = \frac{27\text{V}}{23\text{mA}} \approx 1.174\text{k}\Omega = 1174\Omega$$

---

### 二、 求解限流电阻的最小值 $R_{\min}$

为了保护稳压管不被烧毁，即使在最极端的条件下，流过稳压管的电流也绝对不能超过它的最大允许电流 $I_{ZM}$。

**最危险的条件**是指：**输入电压最高**（推高总电流），同时**负载分走的电流最小**（没人分担，电流全涌向稳压管）。

在这个临界状态下，总电流 $I_R$ 为：


$$I_{R} = I_{ZM} + I_{L\min} = 30\text{mA} + 9\text{mA} = 39\text{mA}$$

此时，电阻两端的电压差是最大的（$U_{I\max} - U_Z$）。根据欧姆定律，限流电阻的最小阻值为：


$$R_{\min} = \frac{U_{I\max} - U_Z}{I_{ZM} + I_{L\min}} = \frac{55\text{V} - 18\text{V}}{39\text{mA}} = \frac{37\text{V}}{39\text{mA}} \approx 0.949\text{k}\Omega = 949\Omega$$

---

### 三、 总结结论

限流电阻 $R$ 的取值范围应该介于保证稳压管“不熄灭”与“不烧毁”之间：

$$\mathbf{949\Omega \le R \le 1174\Omega}$$


（或写为 $\mathbf{0.949\text{k}\Omega \le R \le 1.174\text{k}\Omega}$）
