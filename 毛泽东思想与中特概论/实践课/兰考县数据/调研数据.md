### 1探寻乡村振兴的新质力量—— 南开大学中国式现代化张庄村工作站2024寒假行
来源：开封网 作者：全媒体记者 杨静 通讯员 葛宇洋 报道 发布时间：2024-01-25 17:46:49
1月11日至13日，南开大学中国式现代化张庄村工作站一行9人，在南开大学经济学院城市与区域经济研究所副书记、副教授高雪莲的带领下，走进河南兰考进行座谈走访、互动交流和实地考察，领悟“新质生产力”在兰考爆发的着力点，探寻中国乡村振兴的新质力量。
在兰考县农业农村局，南开大学师生详细了解了兰考县高标准农田建设取得的成就。2023年5月，兰考成功入选整县级推进高标准农田建设试点。以此为契机，兰考县坚持把高标准农田建设作为“一举应多变、一招求多效”的战略举措，探索建立“投融建运管”一体化的有效运营模式。高标准农田建设为兰考农业高质量发展注入了新活力，是新质生产力的重要体现，为开封、河南乃至全国做出了先行示范。
在兰考县林业中心，南开大学师生从兰考泡桐产业发展和经济果林种植成效两个方面，进一步了解了兰考县林业产业发展情况。泡桐是焦裕禄同志为治理兰考风沙灾害，带领群众种植的林木。目前，兰考县约有600多万棵泡桐树，为全国95%的高档民族乐器提供板材。林木产业不仅止于泡桐，TATA木门、索菲亚、喜临门等一批龙头企业入驻兰考，兰考县快速形成了以兰考经开区为龙头、六个乡镇配套产业园为支撑的“一区多园”协同发展格局，在市场竞争中走向高级化和现代化。这被兰考人亲切地概括为：“一个人、一棵树、一种精神、一个产业”，体现了生机勃发的林业新质生产力。此外，兰考林业部门独辟蹊径，大力加强生态防护廊道建设与绿化建设，将黄河护岸林与护路林、村外农田防护林网及现有成片林相融合，创造性地设计出三层绿化带防护景观林。不仅有效治理了黄河滩地肆虐的风沙，城市美观绿化效果也显著增强，也为木器产业提供原材料。不仅如此，兰考县还与河南省农科院深入合作，配种育苗，不断丰富水果林产品，提升果木产量与质量，为果农增收提供有力保障。兰考林业一步一步扎实护林，推进融林网、林业、特色果品于一体的高质量新林业链条，为兰考新质发展注入了生机活力。
此次社会实践令师生一行深刻体悟到兰考在乡村振兴中贡献的新质力量。兰考人民在焦裕禄精神的指引下，勇于奋斗，各级政府部门敢于创新，深入研究创设了诸多因地制宜的独特发展模式和政策措施，令协同创新成为新质生产力的源泉活水，令兰考成为全国乡村振兴的前沿阵地。南开大学在农药化学、“以虫治虫理等诸多方面有强劲的优势，期待双方坚实合作，以南开大学中国式现代化兰考县张庄村工作站建设为契机，深入推进高校科研成果服务兰考县乡村振兴责无旁贷，为中国式乡村现代化发展注入新动能。

### 2筑牢产业数智化底座，为新质生产力强基赋能
从中央经济工作会议部署到全国两会频繁提及，新质生产力一词近期持续引发社会关注与热议。如何加快形成新质生产力？破题关键在于技术革命性突破、生产要素创新性配置、产业深度转型升级。“在数字时代，以AI、大数据、云计算为代表的数字技术的革命性突破，能引发传统生产要素以及以数据为代表的新生产要素的融合和创新配置，加速产业智能化进程，驱动生产力从‘量变’到‘质变’，推动数智生产力跃迁。”华为混合云总裁、主机上云军团CEO尚海峰表示。
深化大模型落地应用，赋能千行百业数智升级
全天候监控煤矿作业影像、智能调度规避交通拥堵、农田里的机器自动灌溉施肥…………人工智能作为新一轮科技革命和产业变革的重要驱动力，在各行各业中被广泛应用。今年政府工作报告中“人工智能+”的新提法首次出现，进一步凸显了人工智能在科技生态中的核心位置。
大模型是人工智能领域的重要发展方向，最新数据显示，中国10亿参数规模以上的大模型数量已超100个。“面对大模型的战略机遇，我们应当加强大模型与行业场景的深度融合，探索新兴的应用场景与商业模式。”尚海峰强调。
以煤炭行业为例，依托盘古大模型开启了山东能源集团的煤矿智能化建设之路。基于盘古视觉大模型，云鼎科技和华为云打造了防冲卸压AI监管系统，作业影像实时上传到集控室，精准识别把握相关参数，降低人工核验工作量80%；在监测矿井安全方面，通过掘进安全质量智能监管系统，能对作业环境实现24小时监管和情况分析，及时执行报警和停机，切实筑牢安全防线。此外，盘古矿山大模型还能带来经济效益，在重介选煤场景，利用盘古矿山大模型构筑的重介选煤分选密度智能控制系统，能精准把控煤炭质量，提高了精煤产率。截至目前，山东能源已在26个单位开发和实施首批人工智能应用，华为云盘古矿山大模型也从最初的3个验证场景发展至21个应用场景已开发40余个，持续赋能矿山行业升级。
盘古大模型只是大模型落地行业应用的一道缩影，还有更多行业大模型在电子信息、医疗、交通等众多领域“大展身手”，带来飞跃性的效能提升，助力千行百业迈向新质态。
释放数据要素潜能，打造城市级数智建设新典范
数字时代，数据成为第五大生产要素，其地位和作用愈发凸显。随之而来的是数据量呈现指数级增长，尤其在智慧城市建设中，汇聚了包括交通流量、环境监测、人口分布等各个领域的海量数据，传统运行模式下往往难以对这些数据进行采集、存取和挖掘分析，也无法发挥数据要素的价值及其赋能作用。
上海数据集团携手华为云联合打造了城市级数据空间基础设施——“天机・智信”平台，该平台以华为云Stack云底座为基础，具备数据汇聚存储、治理加工、开发利用及智能化应用提供全链路能力。数据安全方面，在云数智融合、隐私计算等技术加持下，保障公共数据与行业数据、企业之间的数据在安全领域内进行流转；数据应用方面，通过公共数据授权运营平台，覆盖普惠金融、跨境贸易、医疗健康等领域，实现了传统多业务场景的数据开放、数据共享、数据授权和数据价值创新；数据开发方面，为开发利用方打造“拎包入住”的开发环境，满足数据产品的开发、流通、监管、应用全流程需求。
不难发现，借助“数据要素+算力基础设施+应用场景”的模式，推进了数据要素在生产活动和价值创造中的价值化进程，实现了对资本、劳动力和技术等传统要素的赋能，为发展新质生产力提供不竭动力。
以工业互联网为抓手，助力传统产业“智改数转”
传统产业是现代化产业体系的根基，也是培育和发展新质生产力的基础。尚海峰表示，加快发展以工业互联网为核心的智能制造，促进传统产业的数智化升级，推进新型工业化，将是新质生产力的重要落脚点和突破口。
“首先应推进工业数据价值化，实现工业数据的高效采集、融合打通、价值挖掘和合规使用；同时深化工业智能化应用，实现从单点应用、局部优化、业务贯通到协同发展的智能化升级；此外还应加大工业软件云化，解决软件开发门槛高、周期长，且异构集成成本高昂等问题。”尚海峰进一步提出。
河南省兰考县风、光等可再生资源开发条件优越，如何解决风、光不稳定、充分实现资源转化和利用是一直以来困扰当地的难题。为此，兰考县供电公司、国网河南电力联合华为云共同打造了基于华为云Stack的能源互联网平台，借助数据中台、物联网、智能数据湖助力电力负荷数据秒级入湖，建立更精细的负荷预测模型，精确预测清洁能源发电量，突破性实现5×24小时不间断新能源供电，新能源就地消纳率快速提升。目前，全县可再生能源发电装机达128.9万千瓦，比2016年增长了31倍。随着兰考能源互联网平台落成，全县可再生能源发电量占全社会用电量的比重也从21%提高到了97.7%。
“兰考模式”行之有效的背后映射出工业互联网“触角”的不断延伸，形成技术要素和生产要素的全面互联，实现传统产业数字化、网络化、自动化、智能化，发展成为新质生产力的主阵地。
从前沿技术到应用场景，从数字底座到数智城市，从工业互联网到传统产业转型升级，数字技术赋能各行各业的创新成果竞相涌现，彰显出数智生产力的能力所在。培育和发展新质生产力并非一蹴而就，而是涉及方方面面的系统工程，必须坚持久久为功，持续推进关键核心技术突破，推动数智生产力跃迁升级，才能牢牢把握发展新质生产力的主动权，收获高质量发展的累累硕果。

### 3绿电如何“长”出新质生产力？兰考探路丨顶端观察
顶端新闻记者 高瞻展 周茜
11月7日，国务院办公厅发布《关于加快场景培育和开放推动新场景大规模应用的实施意见》（国办发〔2025〕37号），从国家战略高度对新场景大规模应用作出系统性部署。
作为国家能源局批复的全国首个农村能源革命试点县，河南省兰考县积极贯彻国家政策，聚焦清洁能源领域，系统构建九大应用场景，让一度度绿电从田野间、屋顶上“生长”出来，点亮万家灯火，驱动产业新生，绘就了一幅能源惠民、生态宜居的绿色画卷。
```
全村实现绿电供应
农户省钱、集体增收
```
场景是连接技术和产业的纽带、打通研发和市场的桥梁。在国办发〔2025〕37号文中，“推动新场景大规模应用”被提升至培育发展新质生产力、推动经济社会高质量发展的关键地位。
零碳乡村的场景，已经成为兰考县付楼村村民们的日常。
村东头池塘长廊上，420多块光伏板如粼粼波光。村民们的屋顶上，蓝色光伏板在阳光下熠熠生辉。村口的“风光储充放”一体化充电站，不仅服务本村车辆，也吸引着南来北往的过客。
“以前用电有阶梯价，最高每度八毛六，空调都不敢常开。现在用上村里的绿电，只要五毛钱一度，省心又省钱。”村民付丽萍笑着说。
“农户出屋顶空间资源，国家电投综合智慧能源公司投建光伏设施，通过‘央企+村集体企业’联合建设模式，创新推进‘零碳乡村’场景建设。”付楼村党支部书记赵六红介绍，通过整村零碳化改造，推进农村源网荷储一体化、农村共富工坊等创新模式，全村226户全部实现绿电供应，全村绿电消纳率超过50%。村民用电便宜了，富余的绿电还能供给村内企业或卖给大电网，助力乡村经济发展。
作为兰考县最具特色的“王牌场景”，以付楼村为代表的“零碳乡村”实现系统化复制推广。据了解，“十五五”期间，兰考将打造100个零碳村庄，能源从“远方来”到“身边取”，正惠及越来越多的乡村。
```
“零碳园区”绿电直供
降本招商“以绿制绿”
```
在兰考国电投新能源产业园，清洁能源的应用场景从民生领域延伸至产业核心，成为驱动经济增长的绿色引擎。通过工业源网荷储一体化等创新场景，园区为企业提供绿电，显著降低用能成本，形成了独具特色的“绿电招商”优势。
走进华耀绿能5GW新型光伏组件项目车间，自动化生产线高速运转。“我们工厂年用电约2000万度，部分使用园区绿电后，电价每度降低约0.15元，预计一年能省下150万到200万元。”项目负责人王建坦言。更关键的是，绿电消费带来的“绿证”，为企业产品进入国际市场提供了“通行证”。
低廉稳定的绿色能源，更吸引了产业链上下游企业聚集。
产业园引入的全固态电池企业——北京纯锂新能源科技有限公司，看中的正是兰考提供的丰富应用场景和绿电保障。“我们的全固态电池系统完成了实证测试，安全性突出。目前，全自动化生产线已实现了全固态电池的连续批量生产。”公司董事长杨帆介绍道。
国家电投综合智慧能源公司兰考项目负责人王震介绍说，国电投新能源产业园的成功实践，验证了“零碳园区”场景的经济与技术可行性。绿色能源在产业园区场景化的系统化应用，成为了驱动投资、聚集产业、提升区域竞争力的核心竞争力。
```
从场景试验到方案输出
构建县域能源革命新范式
```
兰考的场景探索不止于零碳乡村、零碳园区的重点突破，而是通过系统集成绿色交通、绿色算力、智能微电网等九大场景，构建覆盖“源、网、荷、储”的县域新型能源体系。
如今，这些实践正从“试验田”升华为可复制、可推广的标准化方案。
12月11日，在兰考举办的中国水利电力质量管理协会建设专委会成立大会暨农村能源革命技术产品方案研讨会上，面对台下100余位新能源行业专家、学者、上下游企业、行业协会代表，开封市委常委、兰考县委书记陈维忠在《兰考县农村清洁能源应用场景建设方案》的报告中系统介绍了兰考县和国家电投综合智慧能源公司联合发布的九大新能源应用场景，并诚邀新能源产业链上下游企业到兰考九大场景中开展创新应用。
“我们聚焦清洁能源领域，着力打通‘技术突破—场景验证—产业应用—体系升级’发展路径。”陈维忠在致辞中表示。这份方案，是对兰考多年试点经验的阶段性系统总结，标志着其从先行先试迈向标准输出的新阶段。
方案详细构建了九大新能源应用场景：绿色交通领域，正加快构建“县城5分钟、乡镇10分钟充电圈”；绿色算力领域，依托绿电优势承接非实时算力需求，将能源优势转化为数字经济基座；生物基能源领域，让秸秆、畜禽粪污“变废为宝”，构建循环经济链条……
清洁能源领域一个个鲜活的应用场景，被提炼为标准化的技术路径与运营机制，兰考县坚持“央企供应链牵引+地方应用场景示范+绿电产业转型”，为广大县域和产业园区提供了一条可复制、可推广的绿色转型路径，也交出一份兼具生态效益与民生温度的“双碳”答卷。

### 4麦浪翻金处，探访兰考的“新质生产力”跃迁
中原麦浪涌，丰收图景新。日前，“记者之家”大学堂——以农业新质生产力推进农业强国建设研学活动在河南举行，全国近百名“三农”新闻工作者走进兰考县代庄村，在这片焦裕禄精神浸润的土地，实地调研乡村振兴示范新场景。
#### 从亩产23.1公斤到吨粮田
代庄村丰收广场一侧的展览馆内，有一组数据令人记忆犹新：焦裕禄带领兰考人民治理风沙前，兰考全县小麦亩产仅23.1公斤；如今，经过一代代人的努力，通过高标准农田建设、良种培育和耕作技术革新等方式，小麦平均亩产已稳定超过500公斤。
历史记载，黄河素有“铜头铁尾豆腐腰”之说，兰考位于九曲黄河最后一道弯，是典型的“豆腐腰”地段。自行河以来，黄河在兰考境内多次泛滥改道，大小决溢143次，形成了风沙、内涝、盐碱三大自然灾害。20世纪五六十年代，兰考耕地面积不足100万亩，其中风沙地24万亩、涝地36万亩、盐碱地26万亩。

#### 因地制宜 “三融合”澎湃数智化转型
党的二十届三中全会再次强调“因地制宜发展新质生产力”。短短11个字，铿锵有力回答了发展什么和如何发展之问。
中国移动为白山热电有限责任公司搭建5G+“智慧电厂”综合管理平台，以智能手段排查厂区的生产隐患
着眼信息服务业，既是形成新质生产力的重要领域，又为其他领域培育新质生产力提供着重要支撑。细看中国移动近年来各项举措，不论是着力推动“三个融合”，还是加快推进数、算、智创新应用发展，其目的都是为高质量发展培育壮大新产业、新模式、新动能，都在为培育发展新质生产力因地制宜注智赋能。
新型工业化成为发展新质生产力的主阵地。作为老工业基地，东北地区传统产业自从有了5G加持，迸发新生机。中国移动为长白山脚下能源企业打造的“5G智慧电厂”，为厂区提供信息化的安全生产管理手段，智能巡检、智能安防等场景应用，让无人化、自动化之光照进现实。在中部地区，面向化工产业，中国移动助力打造武汉首家5G+智能化工厂，实现了2.5平方千米炼油厂区石化装置的5G智能化改造，为化工企业拧紧“安全阀”。从外围辅助到核心环节，中国移动不仅助力单个企业向智能化深度转型，也在规模赋能传统制造业高质量发展。
农业现代化是发展新质生产力的着力点。作为传统种植业大国，我国粮食增产增收意义重大。在中部地区，中国移动为河南兰考县打造5G高标准农田，粮食作物增产约10%，农药施用量可减少约20%，农民年均增收约650元/亩。“蓝色粮仓”也因5G赋能而“渔歌嘹亮”。在东南沿海，中国移动为福建宁德三都澳海域打造5G智慧海洋样板区，基本实现50公里海域全覆盖，鱼群的活动情况及周边的海水质量得到实时监测，不仅降低了人工成本，还增加了经济收益。中国移动以新技术深度覆盖农业产销全链条，在华南，创新“覃塘富硒米云认养”模式，打造“互联网+农产品+直播”新模式，推动“桂字号”农产品走向全国。
人民日益增长的美好生活需要在发展新质生产力中不断得到满足。在医疗领域，中国移动采用“5G-A+区块链+AI”技术，成功实现5G-A无人机在河北的紧急医疗物资运输，完成医院与血站间血液低空高效配送。在教育领域，中国移动打造的“云课堂”，让深处高原深处的四川甘孜藏族自治州的孩子能和城里孩子同上一堂课。在交通领域，中国移动通过“5G+云网+车路协同”技术，助力京雄高速北京段成为国内首条真正意义上的智慧高速公路；通过“5G+北斗”室内导航系统，在重庆填补了国内地下隧道无卫星导航的技术空白；基于5G-A通感一体网络能力，在云南保山机场构建了空地一体监测系统，解决机场低空、跑道侵入防控等管理痛点问题。
社会治理现代化同样离不开治理方式数智化转型。在西北，数字政府建设有了“甘肃经验”。中国移动助力甘肃省探索数字政府建设新模式，初步走出了一条符合甘肃实际、技术架构一流、应用特色鲜明的数字政府建设新路径，全省政务服务事项全程网办率达到98％以上。在东南沿海，中国移动基于物联网、大数据、5G等技术，构建园区环境综合监测系统，对广东东莞市生产企业、工业园区、化工园区的大气、水、土壤、固危废等进行在线实时监测，从多目标、多维度、全生命周期对区域环境进行数字治理。大到数字政府建设，小到周围空间管理，中国移动正助力社会以“新”焕新。
